## [PT-BR] Visão geral do projeto
Este projeto de Análise Exploratória de Dados (EDA) foi desenvolvido para dar suporte à tomada de decisão executiva da rede Alura Store. O objetivo central foi processar a base de vendas, identificar padrões de consumo, avaliar custos logísticos e, por fim, recomendar estrategicamente o fechamento da unidade menos rentável da rede.

## [EN] Project Overview
This project involves an Exploratory Data Analysis (EDA) developed to support executive decision-making for the Alura Store network. The primary objective was to process sales data, identify consumption patterns, evaluate logistics costs, and strategically recommend the decommissioning of the network's least profitable unit.

## Stack tecnológica
- **Python & Pandas**: Limpeza de dados nulos, manipulação de DataFrames e cálculo de KPIs (faturamento, ticket médio, rentabilidade).

- **Plotly & Streamlit**: Dashboards interativos e visualização dinâmica.
- **Google Colab**: Ambiente de prototipagem e documentação técnica.

A análise verificou métricas de satisfação, volume de vendas por categoria e eficiência logística. O insight principal apontou a **loja 4** como o gargalo operacional da rede.
